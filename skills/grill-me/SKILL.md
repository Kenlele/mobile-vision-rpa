# Grill-Me Skill (Interactive Interviewer)

## Overview
The `grill-me` skill turns the agent into a rigorous architectural interviewer to stress-test plans, designs, or test cases before execution.

## Execution Rules
1. Ask one targeted question at a time.
2. Provide pre-selected recommended options.
3. Check project codebase first to prevent asking redundant details.
4. Synthesize final agreed requirements into an actionable spec.
