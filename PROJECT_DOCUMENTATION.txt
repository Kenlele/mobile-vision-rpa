一、 極簡 3 步驟快速開始 (Quick Start)
--------------------------------------------------------------------------------

步驟 1：開啟與編輯設定檔 (config.ini)
        在專案根目錄下的 `config.ini` 中貼上您的 Gemini API Key：
        
        [LLM]
        gemini_api_key = 您的_Gemini_API_Key_貼在此處
        model_name = gemini-2.5-flash


步驟 2：開啟終端機並進入專案目錄
        $ cd mobile-vision-rpa


步驟 3：直接執行測試
        方式 A (單行指定任務)：
        $ python main.py --prompt "幫我打開相簿"

        方式 B (互動模式)：
        $ python main.py
        👉 請輸入 Prompt 指示: 幫我打開相簿

※ 系統亮點：專案預設全自動連結您的 Xcode iOS 模擬器 (driver_type = ios)，亦支援 macOS iPhone 鏡像 (`driver_type = iphone_mirror`)！



--------------------------------------------------------------------------------
二、 專案架構與元件職責說明
--------------------------------------------------------------------------------

1. config.ini (通用組態設定檔)
   - 職責：全專案唯一的設定入口。管理 Gemini API Key、模型種類、驅動模式與最大執行步驟數。

2. main.py (互動式主程式入口點)
   - 職責：全專案唯一的 CLI 入口。具備自動偵測與切換專案虛擬環境功能。

3. core/skill_manager.py (Skill 自主學習與記憶引擎)
   - 職責：比對歷史 Skill 庫。若首次執行新任務，將於成功後自動生成 Markdown SKILL.md 檔；後續遇到同類任務直接復用。

4. skills/ (動態生成之 Skill 知識庫)
   - 職責：存放由 AI 自動學習生成的結構化 SKILL.md 檔案，實現無寫死 (Zero Hardcoding) 測試腳本累積。

5. core/agent.py (純 AI Vision 任務執行心臟)
   - 職責：調度 Skill 引擎與 Vision LLM 規劃器，控制「截圖 -> 決策 -> 操作 -> 斷言評判 -> 學習儲存」自動化迴圈。

6. core/runner.py (框架組裝與報告生成器)
   - 職責：負責組裝各層元件並輸出結構化的測試執行報告。

7. ai/llm_planner.py (Gemini Vision LLM 大腦)
   - 職責：將手機截圖與任務 Goal 送交 Gemini Vision 分析，判斷畫面目標與輸出像素座標 JSON。

8. drivers/ios_driver.py (iOS 模擬器控制器)
   - 職責：自動喚醒 macOS 模擬器視窗與裝置，透過 xcrun simctl 動態搜尋 App 套件並執行原生操作。

9. drivers/iphone_mirror_driver.py (macOS iPhone 鏡像實體機控制器)
   - 職責：控制實體 iPhone 之 macOS 鏡像視窗。

10. config/settings.py (全域設定載入器)
    - 職責：自動優先讀取 `config.ini` 的設定，備用讀取環境變數。
