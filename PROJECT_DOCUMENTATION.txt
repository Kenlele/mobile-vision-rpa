一、 極簡 3 步驟快速開始 (Quick Start)
--------------------------------------------------------------------------------

步驟 1：開啟與編輯設定檔 (config.ini)
        在專案根目錄下的 `config.ini` 中填入您的 AI API Key (例如 Gemini 或 OpenAI)：
        
        [LLM]
        provider = gemini
        gemini_api_key = 您的_Gemini_API_Key_貼在此處
        openai_api_key = 

        ※ 無須改動任何 Python 程式碼，亦無須在 Shell 設定環境變數。

步驟 2：開啟終端機並進入專案目錄
        $ cd /Users/yonglinlai/Desktop/mobile-vision-rpa

步驟 3：直接執行測試
        方式 A (單行指定任務)：
        $ python main.py --prompt "幫我打開相簿"

        方式 B (互動模式)：
        $ python main.py
        👉 請輸入 Prompt 指示: 幫我打開相簿

※ 系統亮點：程式會自動啟動專案虛擬環境 (venv)、自動啟動 macOS iOS 模擬器視窗與裝置，並自動載入或生成測試 Skill，完全無須手動介入！


--------------------------------------------------------------------------------
二、 專案架構與元件職責說明
--------------------------------------------------------------------------------

1. config.ini (通用組態設定檔)
   - 職責：全專案唯一的設定入口。管理 AI API Key (Gemini/OpenAI)、模型種類、驅動模式與最大執行步驟數。

2. main.py (互動式主程式入口點)
   - 職責：全專案唯一的 CLI 入口。具備自動偵測與切換專案虛擬環境功能。

3. core/skill_manager.py (Skill 自主學習與記憶引擎)
   - 職責：比對歷史 Skill 庫。若首次執行新任務，將於成功後自動生成 Markdown SKILL.md 檔；後續遇到同類任務直接復用。

4. skills/ (動態生成之 Skill 知識庫)
   - 職責：存放由 AI 自動學習生成的結構化 SKILL.md 檔案，實現無寫死 (Zero Hardcoding) 測試腳本累積。


5. core/agent.py (純 AI Vision 任務執行心臟)
   - 職責：調度 Skill 引擎與 Vision LLM 規劃器，控制「截圖 -> 決策 -> 操作 -> 斷言評判 -> 學習儲存」自動化迴圈。

6. core/runner.py (框架組裝與報告生成器)
   - 職責：負責組裝各層元件並輸出結構化的測試執行報告。

7. ai/llm_planner.py (Vision LLM 多模態大腦)
   - 職責：將手機截圖與任務 Goal 送交 Vision LLM 分析，判斷畫面目標與輸出像素座標 JSON。

8. drivers/ios_driver.py (iOS 實體控制器)
   - 職責：自動喚醒 macOS 模擬器視窗與裝置，透過 xcrun simctl 動態搜尋 App 套件並執行原生操作。

9. config/settings.py (全域設定載入器)
   - 職責：自動優先讀取 `config.ini` 的設定，備用讀取環境變數。

三、 純 AI Vision + Skill 雙引擎工作流程
--------------------------------------------------------------------------------

┌──────────────┐      ┌─────────────────────────┐      ┌─────────────────────────┐
│ 輸入測試 Prompt│ ───> │ SkillManager 比對已知檔案│ ───> │ (若有) 🚀 直接復用 Skill │
└──────────────┘      └─────────────────────────┘      └─────────────────────────┘
                                   │ (若無)                                  │
                                   ▼                                         │
                      ┌─────────────────────────┐                            │
                      │ ⚡ 啟動 AI 視覺探索決策 │                            │
                      └─────────────────────────┘                            │
                                   │                                         │
                                   ▼                                         │
                      ┌─────────────────────────┐                            │
                      │ 執行模擬器原生 Touch/Input│ <────────────────────────┘
                      └─────────────────────────┘
                                   │
                                   ▼
                      ┌─────────────────────────┐      ┌──────────────┐
                      │ ✨ 自動學習生成新 Skill │ ───> │ 產出測試報告 │
                      └─────────────────────────┘      └──────────────┘

1. 任務接收：輸入測試指令（如「幫我打開相簿」）。
2. Skill 比對：SkillManager 檢索 `skills/`，若命中則直接執行，不耗費額外 AI 探索時間。
3. 動態探索：若為新任務，由 Vision LLM 分析畫面截圖並結合 xcrun simctl 動態尋找系統 App。
4. 自動學習：測試成功後，系統自動將成功經驗萃取為 SKILL.md 寫入 `skills/` 進行持久化。
5. 產出報告：最後印出包含執行步驟與狀態的 Summary Report。


--------------------------------------------------------------------------------
四、 根據實務經驗建議與未來加強方向 (Best Practices & Future Enhancements)
--------------------------------------------------------------------------------

1. Skill 庫的版本控管 (Skill Registry in Git)
   - 建議將 `skills/` 產生的 `SKILL.md` 檔案納入 Git 提交。這樣團隊成員可以直接共用 AI 自動學習出來的自動化測試案例，無需重跑探索階段。

2. 雙重定位與斷言機制 (Visual Locator + Self-Assertion)
   - 現有機制透過 macOS Native Apple Vision OCR 與 Screen Delta 變更檢測器 (vision/ 模組) 輔助 Vision LLM。


3. 多裝置並行測試支援 (Multi-device Support)
   - 目前 `config.ini` 設定 `udid = booted` 可控單一模擬器。未來可透過擴充 `--udid` 參數，實現多台模擬器（如 iPhone 15 Pro, iPad Air）同時並行跑測試。

4. 異常重試與自動修復 (Self-Healing RPA)
   - 當 Skill 復用遇到 App 改版或介面位移時， Skill Engine 可自動觸發「重新探索 (Re-Discovery)」，並自動更新 `skills_store/` 中的舊 Skill 檔案。
